# Julia's Kitchen

Записная книжка рецептов Юли: https://karasuoshi.github.io/JK/

Рецепты удобно смотреть с телефона прямо во время готовки:
- ингредиенты и шаги можно отмечать галочками;
- пересчёт порций;
- таймеры по времени из шагов;
- экран не гаснет;
- после первого открытия сайт работает без интернета.

Есть разделы по категориям и подбор рецептов по продуктам.

## Как добавляются рецепты

Только через агентов (Claude, ChatGPT и др.), без форм на сайте. Агент кладёт файл `recipes/<id>.json`, после чего GitHub сам проверяет рецепт и собирает сайт. Полная инструкция для агентов — в [AGENTS.md](AGENTS.md).

## Файлы

| Путь | Что это |
|---|---|
| `recipes/` | рецепты, один файл = один рецепт |
| `photos/` | фото блюд |
| `cards/` | оригинальные карточки Юли |
| `data/categories.json` | категории |
| `data/products.json` | справочник продуктов для раздела «По продуктам» |
| `schema/recipe.schema.json` | схема рецепта |
| `docs/CARD_PROMPT.md` | промпт, чтобы сделать карточку в GPT |
| `site/` | оформление: стили, скрипты, шрифты, иконки |
| `tools/validate.mjs` | проверка рецептов |
| `tools/build.mjs` | сборка сайта в `_site/` |
| `tools/render.mjs` | автокарточки и фото из карточек |
| `.github/workflows/pages.yml` | автосборка и публикация |

Шрифты: Marck Script, Caveat, Lora (лицензия SIL OFL, файлы лежат в `site/fonts/`).
